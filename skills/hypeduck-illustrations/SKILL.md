# HypeDuck 오리 일러스트

## Overview

글의 핵심 판단·구조·상태·은유 하나를 골라, 하입덕 노란 오리가 그 동작을 수행하는 16:9 손그림 해설 이미지로 만든다. 생성 경로는 이 스킬에 내장돼 있다(OpenRouter). 다른 일러스트 스킬의 `image_gen` 같은 도구 지시는 따르지 말고, 항상 아래 `scripts/gen.mjs`를 쓴다.

스타일 고정값: 순백 배경 · 검정 세선 손그림 · 여백 40%+ · **오리만 컬러**(노랑 #FFD400 몸 + 주황 #FF8A00 부리, 로고 얼굴 고정) · 한국어 손글씨 주석(빨강=경고/결과, 주황=흐름/화살표, 파랑=보조/상태) · 장당 메시지 1개.

## Workflow

1. **글 소화 → shot list.** 인지 앵커(판단·전환점·구조·전후 대비·상태)만 고른다. 본문 삽화는 4~8장, 단일 개념 요청은 1장. 균등 배분 금지 — 그림이 필요 없는 문단은 건너뛴다.
2. **shots JSON 작성.** 작업 폴더(호출 컨텍스트의 산출물 위치)에 `shots.json` 이름으로 저장:

```json
{
  "outDir": "/절대/경로/illustrations",
  "shots": [{
    "file": "01-slug.png",
    "theme": "한 줄 주제 (영어)",
    "structure": "Before/after contrast | Character state | System | Concept metaphor | Filter metaphor | Hand-drawn chart",
    "core": "이 그림이 말하는 단 하나의 의미 (영어)",
    "composition": "장면 묘사 (영어) — The duck이 어디서 무엇을 하는지, 물건·흐름·크기 대비까지 구체적으로. 오리가 핵심 동작의 주체여야 함",
    "labels": "red handwritten \"주석1\" 위치 / blue handwritten \"주석2\" 위치 — 전부 한국어 2~4어절, 최대 4개"
  }]
}
```

3. **생성.** `node <이 스킬 폴더>/scripts/gen.mjs <shots.json 절대경로>` — 인자는 절대경로 권장(cwd 무관). API 키는 env `OPENROUTER_API_KEY`(없으면 `./.env` 또는 `~/.hypeduck.env`에서 탐색), 모델 `google/gemini-3-pro-image`, 마스코트 얼굴은 스크립트가 레퍼런스 이미지로 자동 첨부. 출력은 스크립트가 16:9(1376×768)로 강제하므로 비율 검사는 불필요.
4. **QA — 전 장 Read로 육안 검사:** ① 순백 배경 ② 오리가 핵심 동작 수행(장식이면 실패) ③ 한글 주석 철자 정확 ④ PPT 인포그래픽 느낌 아님 ⑤ 여백 충분(육안 판정 — 경계선이면 통과, 주체가 화면을 꽉 채울 때만 실패). 실패 장만 번호로 재생성: `node gen.mjs <shots.json> 3 5` — 번호는 shots 배열 순서 1부터(최대 2회, 오탈자 반복 시 주석 어절 수를 줄여 재시도).
5. **보고.** 장수·경로·각 장 용도·재생성 이력.

## Common Mistakes

| 실수 | 결과/해법 |
|---|---|
| 주석을 5어절+ 길게 | 한글 오탈자 확률 급증 → 2~4어절로 자르기 |
| composition에서 오리가 구경만 함 | 오리를 빼도 성립하는 그림 = 실패. 동작 주체로 다시 쓰기 |
| 한 장에 여러 메시지 | 설명서가 됨 → 장 분리 |
| labels에 영어/중국어 혼입 | 이미지에 그대로 새겨짐 → 한국어만 |
| 다른 스킬의 image_gen 류 도구 호출 시도 | 이 스킬 경로가 아님 → 반드시 scripts/gen.mjs 사용 |
| 생성 후 QA 생략 | 오탈자·구도 붕괴가 그대로 납품됨 → Read 검사 필수 |
